# Open Scripture app (apps/mobile)

React Native + Expo SDK 57. English UI, no login. Scripture text (KJV, NASB, NIV, NKJV, ESV) is served
through the Convex backend in `packages/backend` — see the root `README.md` for the data flow,
env vars and licensing rules. Highlights, notes and plan progress stay on the device.

UI: paper/gold/oxblood palette, Crimson Pro for scripture and display type, Material Symbols icons
(codepoints in `src/components/ui.tsx`). The reader renders a print-style chapter heading, per-verse
tap → action sheet, floating chapter nav, and an in-reader plan banner (mark day done / next day).

## Screens
- S-01 Onboarding (first run) → `src/app/onboarding.tsx`
- S-03 Bible Reader (chapter text via Convex, highlights, KJV audio) → `src/app/(tabs)/read.tsx`
- Translation sheet (picker, availability from the backend) → `src/components/translation-sheet.tsx`
- S-04 Book & Chapter picker (bottom sheet in the reader) → `src/components/book-sheet.tsx`
- S-05 Verse action sheet (highlight/bookmark/note/copy/share) → `src/components/verse-sheet.tsx`
- Display sheet (text size + theme, opened from the reader) → `src/components/display-sheet.tsx`
- S-06 Search (tab) → `src/app/(tabs)/search.tsx`
- S-07 Plans tab → `src/app/(tabs)/plans.tsx`
- S-08 Plan detail → `src/app/plans/[id].tsx`
- S-09 Plan day → `src/app/plans/[id]/day/[day].tsx`
- S-10 More & Settings → `src/app/(tabs)/more.tsx`

## Data
- Chapter text, exact search, verse lookup, commentary, and audio timings come from Convex.
- The bundle keeps Strong's word data and the semantic vector index. A compact verse-count table preserves their canonical KJV row order without shipping Scripture text.
- 5 plans in `src/assets/plans/` — 3 short (with devotionals) + 2 yearly 365-day tracks, generated by `node scripts/gen-yearly.mjs` (asserts all 1,189 chapters covered exactly once).
- Audio: per-book LibriVox streams in `src/lib/audio.ts`, with verse timing data loaded from Convex.

## Storage (AsyncStorage, all local)
`openscripture.settings` (includes `translation`), `openscripture.position`, `openscripture.highlights`, `openscripture.bookmarks`, `openscripture.notes`, `openscripture.planProgress` — see `CONTRACT.md` for shapes.

## Build
Requires JDK 17 (`~/.jdks/jdk-17.0.20.1+1`) and Android SDK (`~/Android/Sdk`) with
Build-Tools 36.0.0.

```bash
JAVA_HOME=~/.jdks/jdk-17.0.20.1+1 ANDROID_HOME=~/Android/Sdk npx expo prebuild -p android
cd android && JAVA_HOME=~/.jdks/jdk-17.0.20.1+1 ANDROID_HOME=~/Android/Sdk \
  ./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a
# APK: android/app/build/outputs/apk/release/app-release.apk  (signed with the debug keystore — installable)

# Verify 16 KB ZIP and ELF alignment before shipping.
cd ..
ZIPALIGN=~/Android/Sdk/build-tools/36.0.0/zipalign \
  scripts/verify-android-16kb.sh android/app/build/outputs/apk/release/app-release.apk
```

Latest APK: `../../OpenScripture-v1.0.apk` (arm64, ~52MB). Install: copy to phone, or `~/Android/Sdk/platform-tools/adb install OpenScripture-v1.0.apk`.
